## 📌 Про проєкт RE:HUB

**RE:HUB (Reconstruction Hub)** — це інтелектуальна операційна система нового покоління для будівельного сектору, проєктних бюро та девелоперів України. Платформа об'єднує роботу з кресленнями, таблицями, кошторисами та комунікацією в єдиному захищеному робочому просторі, підсиленому ШІ-асистентами.

У будівельній індустрії типовий проєкт розпорошений між десятками каналів: чати в месенджерах, корпоративна пошта, папки в хмарі, сотні версій креслень та безкінечні Excel-таблиці. **RE:HUB вирішує цю проблему, створюючи єдину точку правди (Single Source of Truth).**

## 🏗️ Ключові можливості платформи (All-in-One Scope)

```
┌───────────────────────────────────────────────────────────────────────────────┐
│                           RE:HUB All-in-One Platform                          │
├──────────────────────┬──────────────────────┬─────────────────────────────────┤
│    DATA & ASSETS     │    COMMUNICATION     │          AI CORE ENGINE         │
├──────────────────────┼──────────────────────┼─────────────────────────────────┤
│ • Креслення (PDF/CAD)│ • Корпоративна пошта │ • AI Report & Template Engine   │
│ • Специфікації & ВОР │   проєкту (Inbound)  │ • Project Intelligence (RAG)    │
│ • Кошториси & Excel  │ • Вбудований         │ • Takeoff & Калькулятор вартості│
│ • Контроль версій    │   месенджер & таски  │ • Нормативний валідатор (ДБН)   │
└──────────────────────┴──────────────────────┴─────────────────────────────────┘
```

### 1. 📧 Корпоративна пошта для кожного проєкту
* Кожен створений проєкт автоматично отримує унікальну захищену поштову адресу (`project-code@...`).
* Підрядники, постачальники та замовники можуть надсилати листи, рахунки, прайси чи креслення без необхідності мати акаунт на платформі.
* Платформа автоматично каталогізує вхідні вкладення у відповідний розділ проєкту та передає їх на обробку ШІ.

### 2. 📐 Контроль версій креслень та таблиць
* Прозоре версіонування креслень та специфікацій (ревізії $v1, v2 \dots$).
* Миттєве виявлення відмінностей між версіями без втрати історії правок. Жодних файлів на кшталт `Креслення_остаточний_v3_правки.pdf`.

### 3. 💬 Вбудований месенджер, задачі та права доступу
* Контекстне обговорення деталей проєкту, прив'язане до конкретних креслень, таблиць чи колізій.
* Постановка задач безпосередньо з інтерфейсу перегляду креслення.
* Гранулярні ролі: Головний інженер, Архітектор, Кошторисник, Підрядник, Аудитор.

## 🤖 Кілер-фічі ШІ (AI Capabilities)

### 📊 1. AI Report & Template Engine (Генератор звітів з 1 зразка)
* **Zero-effort створення шаблонів:** Завантажується всього 1 приклад типового звіту компанії (Word/Excel/PDF) — про витрати, зарплати, матеріали чи логістику. ШІ аналізує структуру, витягує змінні поля та створює JSON-схему форми.
* **Автоматичне заповнення:** Інженер обирає звіт і вихідні таблиці проєкту — ШІ самостійно зіставляє дані та заповнює звіт без потреби ручного мапінгу колонок.

### 🔍 2. «NotebookLM для будівництва» (Project Intelligence RAG)
* Інтерактивний діалог з усією базою знань проєкту: кресленнями, відомостями обсягів робіт (ВОР) та договорами.
* Генерація зведених таблиць за будь-яким запитом («Склади зведену таблицю по всій арматурі та бетону по секціях 1 і 2»).
* Сувора валідація з точним цитуванням аркушів, номерів сторінок та пунктів ДБН/ДСТУ — жодних вигаданих фактів.

### 📐 3. Автоматичний Takeoff та розрахунок вартості
* ШІ-парсинг таблиць специфікацій на кресленнях та підрахунок сумарних обсягів матеріалів.
* Зіставлення з прайс-листами постачальників та кошторисними розцінками для швидкого контролю бюджету.
